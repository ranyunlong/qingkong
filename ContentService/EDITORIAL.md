# 首批文章待审包

`editorial-drafts.json` 含与现有 18 个选题一一对应的中文正文；每篇包含适用范围、「为什么可能出现」「现在可以做什么」「何时需要专业帮助」。正文为纯文本；各篇约 400～440 个非空白字符，附机构原始页面、检索日期、审核待核点及引用适用限制。检索日期为 2026-11-21。

全部保持 `status=draft`、`professionalReviewStatus=not_reviewed`、`review=null`。这是可供专业人员审阅的编辑稿，不是已获专业审核的正式文章；没有启动服务、写入数据库或发布任何文章，也未更改种子提纲和服务代码。

主要依据 NIMH、NHS、CDC、FDA、NIH NHLBI／NCCIH、NLM、WHO 与 Cleveland Clinic 的机构页面自行转述。引用机构不代表其认可本应用；原文中的审核标签也不代表本稿经过审核。来源主要面向海外或全球人群，需要中文专业审核者确认适用性和本地求助路径，不直接照搬 911／999／988 等海外号码。临床长时 HRV 资料不能直接作为腕表短时 SDNN 的诊断标准；血氧仪限制不能外推为其他传感器的具体精度结论；一般呼吸资料不能证明本应用一分钟模式的治疗效果。

人工导入现有后台：

1. 启动本地后台并登录后，按标题找到已存在的种子文章，进入编辑；若没有对应文章，再新建。把本包的 `title`、`summary`、`body`、`category`、`sortOrder` 填入表单，封面可保持空白。
2. 来源编辑框只接收 `[{"title":"原页面标题","url":"https://…"}]`。从本包每条 `references` 中保留 `title`、`url`，手工复制成该数组；`publisher`、`retrievedOn`、`applicabilityNote` 留在本待审包供审核者查阅，不作为后台来源字段提交。
3. 保存草稿并查看预览。不要把本包的 `editorialID` 当作线上文章 ID；编辑已有文章要保留其原 UUID，避免同题重复。不要把包内的状态、字数、检索日期、审核清单或 `review` 写入正文或后台审核记录。
4. 专业人员实际复核正文、来源适用性、求助措辞及审核清单后，可继续修改草稿，再通过现有「提交审核 → 记录实际审核人、资质与范围、明确确认 → 明确发布」流程。任何版本改动后重新审核；不能因为资料来自官方页面而跳过专业审核。

本包不含自动导入或发布命令。后台目前的 JSON 编辑接口也可保存草稿，但须人工选择正确的现有文章 ID、仅提交允许的编辑字段，并使用登录会话和 CSRF 保护；整份待审包不能直接提交给编辑接口。
