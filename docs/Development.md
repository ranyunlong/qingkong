## 核心接口与持久化

`QingkongCore` 只放可独立测试的数据和规则：`HealthReading`、`MoodRecord`、`Preferences`、`TrendBucket`、`AudioState`、`AudioCommand`／`AudioReply`、`SyncPayload`／`SyncReceipt`、`ComplicationSnapshot`，以及放松提醒的纯判断规则和本地账本类型。

两端各自持有 `AppServices`，组合 `LocalStore`、`HealthService`、`AudioPlayer`、`Connectivity`。没有跨进程共享播放器或全局服务器。

同步 v1：每条记录有 UUID 和修改时间；以较新版本合并，同时间的删除优先。删除保留墓碑并清空日记文字。每条待同步记录保存在本地；对端成功落盘后发送回执，只确认相同 ID 和版本，旧回执不能清除更新后的待同步状态。重复传送可安全合并。

组件只读受系统文件保护的手表摘要，按系统时间线更新；iPhone 配置通过 WatchConnectivity 到手表后刷新摘要。组件内可单独覆盖指标，默认跟随 iPhone。
