# 小晴空 · 产品功能总表

整理日期：2026-11-21。本文汇总现有功能、本次确定的扩展与纳入规划的建议，不代表新增功能已实现，也不代表现有实现均已完成真机验收。实际验证记录见 [Verification.md](Verification.md)。

2026-11-22 逐项审计：83 个检查点中完整覆盖 77 项、部分完成 6 项（等权覆盖率约 93%）；实现与验收分开统计，详见 [本次审计报告](FeatureAudit-2026-11-22.md)。

## 1. 产品定位与基本约定

**陪你照顾身体，也照顾心情。** 面向正在经历焦虑、希望了解身体变化并获得日常放松支持的人，也适合一般健康与心情记录用户。

- 免费、免注册、无广告、无付费入口；应用内不宣传公司，开发者身份通过应用商店展示。
- 以健康趋势、心情记录、团子陪伴、放松练习、助眠声音与可信知识提供辅助支持，不诊断焦虑症，不承诺治疗效果。
- 信息表达温和、准确，不用单次健康读数给用户贴情绪标签，不用打卡惩罚、倒计时焦虑或负面团子反馈促活。
- 保留 01「晴空」方向、五款团子、晴空蓝／林间绿／海岸青／星夜紫四套场景。iPhone 使用原生系统控件及适用系统版本的玻璃样式，重点颜色跟随场景；Watch 控件保持黑白，组件背景适配系统环境。
- 当前最低系统为 iOS 18、watchOS 11。现有工程、同步和数据兼容约定继续保留。
- 新增 macOS 14+ 伴侣端：本机缓存日／周／月汇总报表、在线专辑与下载、知识库及三端音乐控制。同 Apple ID、同 Wi-Fi 自动连接；CloudKit 私有空间仅同步随机连接凭据，个人内容不进入云端。Mac 默认独立播放；手机通过系统 AirPlay 选择 Mac 后，iPhone 负责实际播放和绝对停止定时，Mac 小晴空同步封面、队列、进度、循环与实际系统输出音量，遥控操作等待手机实际回执。手机／Watch 控制同一手机播放器，AirPlay 音量使用系统原生输出控件，Mac 镜像音量条只读并跟随手机更新，独立播放仍可调节自己的播放器音量；系统只返回通用 AirPlay 名称时镜像至唯一已连接的可信 Mac，多台时不自动选取，不据此改变声音输出；局域网界面连接失效只冻结遥控，不暂停音频，重连不重放操作。汇总报表默认不自动发送，在手机「个性化 → 连接 Mac」逐台授权后仅在手机前台自动同步最近 38 天，也保留手动同步；关闭可离线撤销，账号切换撤销旧授权。CloudKit 信任结构已配置，真实 AirPlay 与锁屏路径待验收。Mac 采用音乐／知识库／报表／设备原生侧栏、底部常驻播放器、队列和图表报表。Mac 不提供陪伴或呼吸练习；当前播放方案见 `plans/2026-11-25-airplay-playback.md`，后续桌面能力见 `plans/2026-11-24-mac-companion.md`，规划项不计已交付。
- Mac 音乐按专辑展示，支持详情、全部／已下载筛选、单曲／整张下载、取消重试删除及空间管理；内置声音归入「随身自然」。连接后的新版手机自动发送公开音乐目录，Mac 校验并原子保存后回执；手机不通过目录同步发送音频或私人阅读状态。Mac 独立播放自行下载音频和封面；AirPlay 期间队列切歌遥控手机，选择本机专辑则先确认手机暂停，再开始 Mac 独立播放。
- Mac 知识库独立获取公共文章，提供分类、标题／摘要／正文搜索、收藏、已读、相关文章、审核／测试标识和参考来源。原生正文支持选择文字，已读／收藏文章及图片在本机离线缓存；不从手机同步文章、收藏或已读。音乐与文章版本独立，手机目录更新不会覆盖文章库。本轮构建与自动检查通过，原生内容窗口观察及真实双机同步仍待验收。
- 2026-11-25 已实际观察整改后的 Mac 原生内容窗口：知识库主页仅文章列表，点选后在右侧全宽阅读，工具栏返回保留搜索与列表位置，底部播放器常驻。专辑采用系统搜索，全部／已下载在 macOS 26 使用原生玻璃胶囊按钮，旧系统保留原生分段筛选；歌曲下载仅显示细环／状态图标，失败可展开说明并重试；内容区取消装饰分割线。内置「随身自然」仅在网络已确认不可用、下载恢复校验结束且没有有效离线在线专辑时作为备用入口；部分专辑至少一首有效持久下载或自动缓存即可优先使用。真实双机同步仍待验收。
- Mac 无播放队列时，播放按钮使用已打开专辑或默认第一张可播专辑的完整队列，从第一首开始；已有队列保持歌曲和位置。循环／上一曲／播放／下一曲／定时按此顺序排列。音量点击后从按钮原位向左悬浮显示胶囊滑块，以加深底色、细边框和强调色滑块区分，离开悬浮区域收起，不参与进度条宽度分配；加载转圈在左侧时间之前紧凑固定占位，不在曲名下增加缓冲文字行。队列单击切歌，当前选中曲目的状态图标在活跃窗口为白色，窗口不活跃时为强调色。
- Mac 提供原生菜单栏播放器，展示封面、曲名和进度，可播放／暂停、切歌、定位、调整音量、循环与定时，也可打开主窗口。独立播放的系统「正在播放」及媒体键共用 Mac 播放器，实际开始播放后才发布系统状态，停止后清除。AirPlay 画面同步期间不再发布重复的 Mac 媒体会话，系统控制由系统接收器处理；小晴空界面操作遥控手机。交接期间系统指令被拒绝，暂停、缓冲、定位和切歌更新实际进度；不提供通知横幅、不申请通知权限。系统面板实际显示和媒体键操作仍待运行验收。
- 本次增加公共内容后台，替代原先“完全无后端”的规划；健康、心情、日记及其分析继续在设备本地处理，不增加云端 AI。

## 2. 客户端完整功能

底部保留「今日、趋势、心情、助眠」四个入口，个性化从顶部进入；知识库先放在心情页，首页提供入口，不增加第五个底部入口。

公共内容默认使用 `https://xqk.geckoai.cn`，iPhone 与 Watch 无需填写服务地址，不显示内容服务设置入口。个性化底部提供 GitHub 开源仓库及 Issues 反馈入口，说明服务端只提供文章和音乐，不接收用户的健康、心情或日记数据。

### 2.1 今日与健康趋势〔已有基础实现〕

- 今日概览：HRV、心率、血氧、心情、心电图及声音入口，显示真实数据的来源与采样时间。
- 通过 HealthKit 读取已有心率、血氧、HRV 与心电图记录；首次启动提供健康连接说明，可稍后授权，无记录使用中性空状态。
- HRV 使用 SDNN、单位 ms；个人基线为此前七个日历日有效日均值的均值，至少三个有效日，不足时显示基线积累中，不从普通心率反推 HRV。
- 心率、HRV、血氧提供日／周／月趋势；iPhone 横向拖动可查看对应数值，纵向拖动保留页面滚动，首页 HRV 小图不抢滚动手势。缺失值保持空缺。
- 心电图提供历史列表、详情和完整波形横向浏览，不保留数值选中交互，不自行诊断或发起测量。
- 保留已有健康变化提醒、可调设置、当天暂停及通知诊断，不继续扩展异常预警种类。提醒不被当作实时医疗监测或系统健康提醒的替代。
- Watch 完成授权和交接后作为主要检测端；连接可用时委托 iPhone 提交通知，实际显示位置遵循系统规则；无法联系 iPhone 时由 Watch 本地通知。不读取私有锁屏状态或单独干预专注模式。
- 通知保留去重、限频和过期保护；点击后进入对应趋势或放松支持。具体规则继续以 [RelaxationReminders.md](RelaxationReminders.md) 为准，本次不擅自删除或修改原有默认开关。

### 2.2 心情记录与个性化〔已有基础实现〕

- 五档心情、五档主观压力、可选文字日记、历史查看与删除；输入框提供占位提示，点击输入区之外收起键盘。
- 本地持久保存；配对设备同步心情与偏好，离线记录恢复连接后补传，按唯一标识去重，删除同步防止旧记录恢复。
- 团子依据用户最近主动记录的心情变化，不根据 HRV 推断表情或情绪。
- 四主题切换；可选的压力换景默认关闭，开启后按当天主动记录联动应用内放松场景。手动换主题关闭联动。
- 壁纸预览、保存与手动设置指引；不自动更换系统桌面。
- 个性化保留健康连接、通知设置、隐私说明及手表组件配置和预览。

### 2.3 安心首页与一分钟放松〔新增，优先〕

- 「安心首页」默认开启，开关位于个性化；放大的团子位于首页标题右侧，与标题文字基线对齐，首页不放开关或额外节奏提示文案。突出心情与放松入口，弱化健康数字；用户可关闭以显示首页健康数据，仍可主动进入趋势，手动选择持久保存。
- iPhone 首页和 Watch 提供明显的「陪我缓一缓」入口，无需先填写记录、读取健康数据或完成测评。
- 选择 1／3／5 分钟，以团子动作、简短文字、默认开启且可关闭的引导声音及手表触感提供舒缓呼吸或安静陪伴；开始与反馈使用正常尺寸原生按钮；进行中不显示暂停或结束按钮，通过左上角返回退出。呼吸团子不拿树叶，身体轮廓与双脚保持固定，通过肩臂抬落、面部与嘴型表现拟人呼吸，呼气时有向外飘散的气流；可随时通过左上角返回退出，不要求憋气或强制完成。
- 陪伴页仅按两种方式选择对应动画，不另设「团子动作」选项：舒缓呼吸使用拟人呼吸，安静陪伴使用轻眨眼、歪头和偶尔挥手的可爱动作；准备页统一显示平静等待、轻轻眨眼，开始陪伴后才播放所选方式的动画，练习暂停时动画同步停止。其他页面的团子动作与解锁不受影响。
- Watch 陪伴主页为单屏，准备时显示团子和开始按钮，开始后仅显示团子，通过左上角返回退出，不显示倒计时、暂停或结束按钮；首页入口右侧更多打开本机设置，时长与方式用列表点选。默认 1 分钟、舒缓呼吸、引导声音和触感开启；触感跟随吸气节律与呼气起点；体能训练／正念延长运行会话维持落腕后的陪伴，屏幕亮度与熄屏仍由 watchOS 管理，退出页面即停止。舒缓呼吸和安静陪伴都在单独授权后持续采集心率，结束后丢弃训练，不保存训练记录，本次最后有效心率保存在本机陪伴记录，不上传或跨端同步。
- 尊重减少动态效果等设置；用户可关闭引导声音或触感。
- 两端完成后自动进入独立结果页，显示本次最后有效心率及采样时间；至少两条相隔 20 秒的本次读数才描述前后变化，不用旧记录或缺失数据替代。鼓励语描述心率变化与照顾自己的行动，不宣称医学恢复或诊断；鼓励语下方可选「好一些／差不多／暂时不想记录」，反馈保存在本机；Watch 结果页左右分页，第一页显示读数与鼓励，第二页选择感受。任一选择保存成功后返回陪伴准备页，直接返回默认未记录感受并退出流程。陪伴回顾与时间线仅在记录含有效心率时显示数值及采样时间，不将未改善视为失败。
- 练习记录保存在本地，可进入回顾；从已有提醒进入时由用户主动开始，不自动开播。

### 2.4 身体与心情时间线、每周回顾〔新增〕

- 按时间关联展示已有健康变化摘要、提醒提交记录、主动心情记录和完成的放松活动。提醒提交不标为“用户已收到”。
- 说明观察依据和采样时间；时间接近不等于因果，不把时间线解释为疾病或情绪诊断。
- 心情记录增加可选生活标签，如工作、家庭、运动、社交、咖啡、饮酒，允许不选。
- 每周在本地汇总记录天数、心情／主观压力分布、放松活动及有数据支持的健康趋势。
- 数据不足时如实说明，不生成虚假的关联或结论；不读取日记推断诊断，不依赖云端 AI。
- 后续接入经授权的睡眠记录，用于昨晚睡眠概览及周回顾；缺失时不估算或补值，不建立新的综合健康评分。
- 时间线、练习与周回顾只保存在本地；新增记录继续提供对应删除能力。

### 2.5 睡前陪伴流程〔新增〕

- 提供可跳过的轻量流程：记下心情 → 选择声音和场景 → 设置停止时间 → 进入安静播放。
- 保存个人喜欢的睡前方案，包含声音、场景和停止时长，下次一键开始；无网络时优先使用可用的本地声音。
- 保留倒计时与截止时间计算，避免后台／重启后定时漂移；不强制每天打卡，不因睡眠记录缺失制造负面反馈。

### 2.6 安心小知识〔新增〕

- 内容围绕理解焦虑、常见身体感受、戒烟等生活变化、睡眠困扰、看懂健康数据与寻求支持。
- 首批计划 15～20 篇经过专业审核的短篇内容。选题示例不直接作为医学结论上线，逐篇核实适用条件和证据。
- 每篇说明“为什么可能出现、现在可以做什么、何时需要专业帮助”，并展示参考来源、审核信息和更新时间；参考来源使用可点击的文字链接。
- 不笼统把症状说成“正常恢复”或“只是焦虑”，不堆砌罕见疾病，也不依据手表读数自动断言症状原因。
- 支持分类、搜索、详情、收藏与已读文章离线缓存；打开知识库或主动刷新时获取最新内容。文章与专辑封面单独按需缓存到本机，重进页面优先复用，解码缩略图有内存上限、封面文件有 30 MiB 空间上限；服务和修订分别识别，未读正文不因此保存。
- 文章更新、修订及撤回在下次成功联网后同步。离线时展示缓存状态与文章更新时间，不假装已检查最新版本。
- 阅读后提供可选放松入口；采用有限的相关阅读，不做无限信息流、恐惧标题或自动频繁推送。
- 首页提供三篇文章的紧凑图文列表，点选直接阅读，更多进入全部安心小知识页面；列表顶部不显示获取成功状态、曲库检查时间或服务器设置入口。

### 2.7 专辑、线上音乐与本地缓存〔新增，保留现有播放器能力〕

- 由现有固定内置声音扩展为专辑和音轨目录，支持封面、介绍、曲目顺序及播放；保留少量内置声音，首次打开或断网也有内容可用。
- 首页显示最新发布且有可播曲目的专辑，封面在上、歌曲列表在下；播放按钮按专辑曲序播放，刷新轮换另一张专辑，更多进入同样布局的全部专辑列表。全部专辑页直接从封面开始，不显示获取成功状态或曲库检查时间；点选单曲后保留当前专辑队列。
- 点选线上音轨即可加载播放并逐步缓存。手机播放器及歌曲列表不显示「完整离线可用／尚未完整缓存」状态文字，列表保留歌曲时长；每首歌固定预留细进度条区域，下载及校验时显示进度，结束后隐藏但不改变行高。下载管理和实际文件校验照常工作。
- 支持主动下载单曲或整张专辑，并查看下载进度、失败重试及删除；不因播放一首就自动下载整张专辑。
- 整张专辑全部曲目已完整校验、可离线播放时隐藏专辑下载图标；单曲的缓存管理入口保留，删除、换版或失效后恢复下载入口。
- 音轨完整保存并验证成功后才标记“离线可用”，播放过一小段不等于整首已下载。缓冲不足且断网时明确提示，不假装继续播放。
- 提供网络偏好及空间管理；默认主动下载和自动补全缓存仅使用 Wi-Fi，蜂窝在线播放由用户主动发起并明确说明流量使用。
- 自动缓存与用户主动下载分开管理：自动缓存可按空间策略清理，主动下载保留至用户删除；播放中的文件不被清理。
- 以稳定音轨标识和文件版本识别缓存，防止后台替换文件后继续误用旧缓存；下架或版本修订在联网后同步处理。
- 保留播放／暂停、上一首／下一首、系统音量、锁屏控制、迷你播放条、后台播放、耳机断开与中断处理。
- 助眠播放器显示可拖动进度条、已播放时间与剩余倒计时，暂停保留位置；音量左侧通过菜单选择单曲循环、顺序循环或随机循环，选择保留在本机。内置循环声音显示当前一轮的实际时间；悬浮播放器使用更高的玻璃容器，放大的封面上下保留空隙，整块胶囊接住点击，暂停按钮有独立触控区域，暂停后隐藏悬浮条，回到助眠可继续播放。
- 播放中仅在助眠主页隐藏重复的播放条；进入助眠子页面或其他选项卡时仍显示。iOS 26.1 起使用系统底部附件区域，页面滚动范围为播放条预留空间；较旧系统保留安全区内嵌播放条。助眠页使用紧凑的原生 AirPlay 输出图标，选中状态由系统实际音频路由决定，不增加接力说明文字，循环使用紧凑按钮。旧 Mac 解码会话保留暂停返回手机的迁移入口；新 AirPlay 路径始终使用手机播放器，Mac 画面连接失联不会停止实际音频。普通暂停和切歌保留所选 AirPlay 输出；系统确认断开 AirPlay 后手机暂停，Mac 退出跟随并恢复独立控制，保持暂停直到用户主动播放。Bonjour 发现结果暂时消失不关闭健康连接；局域网连接失败与系统 AirPlay 断开分别处理。
- 助眠页从播放器封面开始，睡前陪伴与专辑入口位于系统音量下方、停止定时上方；下方展示当前专辑，刷新和更多与首页共用。没有当前播放时读取本机最近播放专辑，首次使用默认最新可播专辑；仅点选后开始播放，最近专辑不上传到服务端。
- 内置「随身自然」离线专辑，使用自然风景封面与简介，包含「林间落雨、慢慢听海、星光慢板」；断网或没有线上专辑时作为默认内容，直接使用随 App 打包的声音，联网后仍可从专辑列表主动选择。
- 保留 15／30／60 分钟停止定时及实时剩余倒计时；自然声音可循环，专辑曲目按当前列表切歌。
- 睡前陪伴的继续、开始、返回与个人方案使用正常字号和至少 44 点触控高度的原生按钮。
- 音频文件由运营方自行上传 OSS，后台仅填写链接，不开发音频上传或转码功能。先按客户端可访问的长期 HTTPS 链接设计；私有桶或过期签名链接需在接入前明确有效地址获取方式。
- 正式音轨需要版权明确、播放稳定，适合循环的自然声音需检查循环接缝；后台记录授权来源、期限及文件版本。

### 2.8 Watch、表盘和 iPhone 小组件〔已有基础实现，随新增功能扩展〕

- Watch 保留健康摘要、三指标详情、快捷心情记录、团子动画、音乐与连接设置。首页图表留白，详情仅图表区域左右切换日／周／月，上方最近读数保持不变。
- 团子页面保留系统时间，团子下方显示心情文字和三列健康数据；页面亮屏活跃时播放短表情动作，随后静止，点按可重播。
- Watch 音乐页保持封面、名称和三个播放按钮；旋转表冠直接调节音量，调节时暂时隐藏播放按钮并显示音量控制。
- 下次点播放时先尝试联系 iPhone，确认可遥控则使用手机；不可达／超时才使用手表本地音频。连接变化不自动让另一端开播，正在播放的本地会话保持稳定。
- 两端同步实际播放状态、音轨和定时，遥控操作等待结果，不假装操作成功。
- 线上曲库可由 iPhone 播放，Watch 负责遥控；手表也已提供独立前台下载，完整校验后可本机播放。手机已缓存不代表手表已下载；离开手表曲库页或退到后台会中断下载，返回后可重试。独立下载／离线播放仍需配对真机验收。
- Watch 提供健康指标复杂功能与心情团子组件，支持已实现的圆形、矩形和适用的单行位置，点按进入对应 App 页面；智能叠放另提供可直接添加的 HRV、心率、血氧矩形卡片，原「小晴空健康」可配置组件保持兼容。Watch 组件沿用系统辅助背景；智能叠放的实际材质效果仍待真机确认。组件刷新服从系统调度，实际材质效果按运行验收记录。
- 系统表盘中的团子保持静态，点按进入 App 里的动画页面，不承诺自定义系统表盘或系统复杂功能持续播放动画。
- iPhone 提供团子主屏幕小号／中号及适用锁屏组件；小号底部三列均按指标名／数值／单位三行居中。
- iPhone 另提供小号／中号「团子音乐」组件，显示最近心情团子、当前歌曲及上一首／播放或暂停／下一首。控制通过 App Intent 操作手机 App 内同一播放器，点按团子或歌曲进入助眠页；冷启动按已缓存目录恢复上次歌曲，失效歌曲或需蜂窝确认时返回错误，不默默换成内置曲目。组件状态使用本机 App Group，不上传到内容后台；系统刷新可能延迟。手机组件运行和后台唤醒留待 TestFlight 验收。
- iPhone 锁屏新增独立圆形「手表电量」：仅显示环形进度，充电时叠加闪电，不显示数字。Watch 应用前台及设备可连接时提供读数；30 分钟未更新显示淡色空环，未知值不补零。电量与采样时间只在配对设备间传递并保存在本机共享容器，系统刷新不保证实时；真机显示与充电状态待验收。
- iPhone 可预览并配置手表健康指标组件、查看添加说明，并通过系统流程导入已有表盘文件；不制作多套自定义表盘套装。

### 2.9 团子陪伴与心情明信片〔纳入后续阶段〕

- 逐步增加团子表情、动作和场景，可随主动记录与放松活动解锁；不设置漏记惩罚、退步、团子生病或负面催促。
- 提供用户主动生成和分享的心情明信片，包含团子、场景及可编辑短句。
- 默认不放入健康值、日记、压力分数或其他敏感内容；分享前由用户预览确认，不自动对外发送。

## 3. 公共内容后台与隐私边界

### 3.1 后台管理

| 模块 | 功能 |
|---|---|
| 管理员入口 | 受保护的后台登录；读者端保持免注册 |
| 文章 | 标题、摘要、正文、封面、分类、参考来源、审核信息、更新时间、排序；草稿、审核、预览、发布、修订、撤回及历史版本恢复 |
| 专辑 | 名称、介绍、封面链接、排序、发布／下架与曲目编排 |
| 音轨 | 名称、所属专辑、音频链接、封面链接、时长、排序、文件版本、版权信息、发布／下架 |
| 公共接口 | 仅返回已发布内容，提供列表、分类、详情及更新／撤回信息；媒体由 OSS 链接提供 |

- 文章审核与发布保留明确操作和记录，未核实的医疗解释不直接发布；首版不建设复杂编辑组织或多级审批。
- 后台不做音频上传、转码或音频文件托管；文章正文支持 HTTPS 图片链接及本地 JPG／PNG／WebP 上传，上传配图保存在公共内容服务的数据卷中，手机端原生显示图文正文。封面继续填写图片链接。
- 防止把临时签名链接当永久音源地址，音轨标识不依赖 URL；专辑、音轨与缓存版本独立管理。
- 内容后台管理公共知识与音频，不提供用户诊断、个体健康分析或健康预警计算。

### 3.2 数据与服务

- 健康原始记录来自设备 HealthKit；心情、日记、练习、收藏与回顾在本地保存。配对设备按必要范围同步，不上传到内容后台。
- 不增加用户账户、健康云同步、广告 SDK、行为画像、自动健康个性化推荐或云端 AI。
- 内容访问会产生必要的网络请求；按实际部署说明基础访问日志、保留期限和服务提供方，不能继续笼统宣称“没有服务器”。
- 上线公共内容服务时，同步更新 App 内隐私说明、官网政策和商店隐私材料，明确公共内容下载与个人健康数据之间的边界。
- 网络故障不阻塞既有本地健康查看、心情记录、内置声音、离线文章及完整下载音轨的使用。

## 4. 开发分期与完成标准

所有本次讨论的功能均列入本表；“后续”表示已记录但不阻塞第一轮交付，不继续增加范围。

| 阶段 | 交付内容 | 主要完成标准 |
|---|---|---|
| 现有基础 | 健康、心情、主题、提醒、两端本地音频、同步、团子与组件 | 按实际版本记录验证范围；不把代码存在或编译通过当作配对真机验收通过 |
| 第一轮：放松与回顾基础 | 安心首页、两端一分钟放松、可选反馈、身体与心情时间线 | 无需健康授权即可开始练习；可退出；减少动态效果有效；本地记录可查看和删除，数据解释不作诊断 |
| 第二轮：内容后台与知识库 | 后台基础、文章审核发布、首批内容、客户端浏览搜索收藏缓存 | 草稿不外露；发布可拉取；修订／撤回可同步；断网可读缓存；健康与日记不进入后台 |
| 第三轮：专辑与线上音频 | 后台专辑／音轨链接管理、在线播放缓存、主动下载、空间管理、Watch 遥控兼容 | OSS 链接可播；未下完不标离线；断网与重试明确；版本更换正确；原定时、锁屏、后台与遥控行为保持 |
| 第四轮：日常陪伴 | 睡前方案、可选标签、每周回顾、经授权的睡眠概览 | 方案可复用；数据不足有中性提示；汇总本地计算；没有因果或疗效承诺 |
| 后续体验 | 更多团子动作与温和解锁、心情明信片、线上音轨下载到 Watch | 分享先预览且默认无敏感内容；手表下载与手机缓存状态明确区分，离线可用需在手表验证 |

补充验收约定：文章需要内容专业审核；在线音频需要真实网络、断网、锁屏、路由和空间不足验证；Watch 需要配对设备验证同步、独立播放和通知。遵循用户要求，不在模拟器添加或操作手机小组件，手机相关视觉效果由用户在 TestFlight 版本确认；手表组件可按用户明确要求在已打开的模拟器中截图检查。

当前后端使用 Python、SQLite 和 Docker，已部署于 `https://xqk.geckoai.cn`。各阶段实际覆盖情况及尚缺的专业内容、版权与真机验收见本次审计；本轮当前修改版未上传 TestFlight、未提交商店审核，历史测试版本记录继续保留。
