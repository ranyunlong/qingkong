# 团子原生页面与屏幕组件

用户已确认：系统组件显示静态心情团子，点按进入 Watch App；App 页面亮屏活跃时播放一次表情动作。iPhone 同时提供带团子的屏幕组件。

- [x] 数据：组件只保存最近有效心情的档位和记录时间，不包含日记、压力与整条记录。兼容旧摘要；本地保存、删除和收到同步都刷新摘要。两端各自使用 HealthKit 数据。
- [x] Watch：原生绘制已认可的五款团子。保留右上角系统时间，团子放大居中，HRV／心率／血氧在下。活跃或心情变更时播放约三秒，结束停在静态；减少动态效果、低亮度、离页或后台时停止，不延长系统驻留时间。
- [x] 组件：Watch 增加圆形、矩形团子入口；保留已有健康指标组件。iPhone 增加小／中主屏幕和锁定屏幕组件。缺失值显示“—”，展示采样时间，系统负责刷新调度。
- [x] 工程：添加 iOS 组件扩展与 App Group；生成器增量更新现有工程，保留版本、签名和用户设置。
- [x] 本地验证：共享逻辑 53 项及记录刷新服务测试通过，完整 iPhone／Watch／两端组件构建通过；已查看 Watch 团子页面与 iPhone 组件图库预览。详见开发验收记录。
- [x] 用户反馈：2026-11-20 用户确认自行发送到 TestFlight 测试后没有问题，并要求停止模拟器测试。保留此反馈作为用户验收结果；未提供对应构建号，不将其记为开发侧真机逐项验证。
- [ ] 后续发布验收：锁屏组件、Watch 新团子复杂功能添加与真实抬腕动画仍需逐项记录。本轮未操作真机、未上传 TestFlight。
