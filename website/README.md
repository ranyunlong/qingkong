# 小晴空介绍网站

两个无构建依赖的静态 H5 页面，适配手机、平板和桌面，可直接部署 `website/` 目录。

- `index.html`：App 介绍、功能、场景预览、开发状态与联系入口。
- `privacy.html`：依据当前原生实现编写的隐私政策。
- `assets/`：来自本项目的图标、小团子和现有自然场景图片；素材来源沿用 `../docs/Assets.md`。

## 本地预览

在项目根目录运行：

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory website
```

打开 `http://127.0.0.1:4187/`。隐私政策为 `http://127.0.0.1:4187/privacy.html`。

## 交互动效

首页使用 CSS 与原生 JavaScript 实现动效，无额外依赖：滚动时分组浮现、趋势线随滚动绘出、心情团子浮起、场景图片缓慢拉近，隐私图标与 App 图标逐渐展开。顶部显示阅读进度并标记当前栏目；首屏设备轻微浮动，离开视野后暂停；场景切换先加载图片再淡入，支持连续切换与键盘操作。

动效以图表、团子等视觉元素自身的位置计算进度，区块离开视野后重置入场状态，再次进入时重新播放。修改 CSS 或 JavaScript 后同步更新两页资源 URL 的版本号，避免线上缓存继续使用旧文件。

按当前产品要求，网页默认开启动画，不提供动效开关，也不会修改系统设置或保存动效偏好。关闭 JavaScript 时内容和初始场景仍可读取。滚动保持浏览器原生行为。

心情团子沿用 `Design/Previews/dumpling-watch.html` 中的五种 SVG 与动作：低落轻叹、疲惫打哈欠、平静呼吸、不错招手、开心挥手笑。首屏手表与心情卡片每 8 秒同步轮换；卡片同时展示五种表情，支持点击与键盘选择，点击大团子可打招呼。展示区离开视野后暂停局部动画；用户聚焦心情控件时暂缓轮换。SVG 渐变 ID 按展示位置区分，避免多份图形相互影响。
